## Engine gaps this document exposes

1. **Post-coverage close rebalance** — equalize AM closes to ~2/week and period totals within 1  
2. **Weekend package bias** — favor full Sun+Sat off for one AM when safe  
3. **SM weekend sacrifice** — allow SM fewer weekend offs than AMs when staffing is tight  
4. **KC mid templates** — optional preferred days (e.g. Farnaz Sun/Tue/Thu/Fri mid; Faiqa Wed/Sat mid) beyond gap-fill only  
5. **Monday manager closes = 0** when KC close night is Monday (already intended; verify never assign manager close Mon)  
6. **Catch-up closes** after VAC/LOA weeks (Norma 3 in final week)
